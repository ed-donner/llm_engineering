# WCAG 3.3.8 — Accessible Authentication (Minimum)

- **Level:** AA
- **Principle:** Understandable
- **Guideline:** 3.3 Input Assistance
- **Understanding:** https://www.w3.org/WAI/WCAG22/Understanding/accessible-authentication-minimum.html

## Requirement
WCAG 3.3.8 Accessible Authentication (Minimum) (Level AA)
Principle: Understandable. Guideline 3.3: Input Assistance.

A cognitive function test (such as remembering a password or solving a puzzle) is not required for any step in an authentication process unless that step provides at least one of the following:

- Alternative: Another authentication method that does not rely on a cognitive function test.
- Mechanism: A mechanism is available to assist the user in completing the cognitive function test.
- Object Recognition: The cognitive function test is to recognize objects.
- Personal Content: The cognitive function test is to identify non-text content the user provided to the website.
Note: "Object recognition" and "Personal content" may be represented by images, video, or audio.
Note: Examples of mechanisms that satisfy this criterion include: <ul> <li>support for password entry by password managers to reduce memory need, and</li> <li>copy and paste to reduce the cognitive burden of re-typing.</li> </ul>

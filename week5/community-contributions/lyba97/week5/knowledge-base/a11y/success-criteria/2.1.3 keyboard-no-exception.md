# WCAG 2.1.3 — Keyboard (No Exception)

- **Level:** AAA
- **Principle:** Operable
- **Guideline:** 2.1 Keyboard Accessible
- **Understanding:** https://www.w3.org/WAI/WCAG22/Understanding/keyboard-no-exception.html

## Requirement
WCAG 2.1.3 Keyboard (No Exception) (Level AAA)
Principle: Operable. Guideline 2.1: Keyboard Accessible.

All functionality of the content is operable through a keyboard interface without requiring specific timings for individual keystrokes.

# WCAG 2.4.9 — Link Purpose (Link Only)

- **Level:** AAA
- **Principle:** Operable
- **Guideline:** 2.4 Navigable
- **Understanding:** https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-link-only.html

## Requirement
WCAG 2.4.9 Link Purpose (Link Only) (Level AAA)
Principle: Operable. Guideline 2.4: Navigable.

A mechanism is available to allow the purpose of each link to be identified from link text alone, except where the purpose of the link would be ambiguous to users in general.

## Related failure techniques
F84, F89

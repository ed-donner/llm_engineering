# WCAG 2.5.6 — Concurrent Input Mechanisms

- **Level:** AAA
- **Principle:** Operable
- **Guideline:** 2.5 Input Modalities
- **Understanding:** https://www.w3.org/WAI/WCAG22/Understanding/concurrent-input-mechanisms.html

## Requirement
WCAG 2.5.6 Concurrent Input Mechanisms (Level AAA)
Principle: Operable. Guideline 2.5: Input Modalities.

Web content does not restrict use of input modalities available on a platform except where the restriction is essential, required to ensure the security of the content, or required to respect user settings.

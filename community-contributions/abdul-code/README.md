# LLM Engineering Exercises

These Projects in Day_1_Projects contain **Day 1 project exercises** from the **Mastering Generative AI and LLMs, AI Automation, AI Agents** course.

The projects focus on practical use of Large Language Models (LLMs) with Python and the OpenAI API. They demonstrate simple, real-world applications involving information extraction, summarization, multilingual generation, and text generation.

## Projects

### 1. Portfolio → Professional Urdu Summary

This project takes a real portfolio website URL, extracts its webpage content, and uses an LLM to identify important professional information.

The model extracts:

* Professional Summary / About
* Education
* Skills
* Work Experience

The extracted information is then organized into a professional summary in Urdu.

#### Workflow

```text
Portfolio URL
     ↓
Webpage Content Extraction
     ↓
LLM
     ↓
Information Extraction & Summarization
     ↓
Professional Urdu Summary
```

#### Key Concepts

* Web content extraction
* System and user prompts
* LLM-based information extraction
* Summarization
* Multilingual text generation

### 2. Commercial Email Subject Generator

This project takes the content of a commercial email and uses an LLM to generate a suitable and professional subject line.

#### Workflow

```text
Email Content
     ↓
System + User Prompts
     ↓
LLM
     ↓
Suggested Email Subject
```

#### Key Concepts

* Prompt design
* System and user messages
* LLM text generation
* Context-aware subject generation

## Technologies Used

* Python
* OpenAI Python Library
* OpenAI API
* Jupyter Notebook
* Web content extraction

## Purpose

These exercises are part of my learning journey through the **Mastering Generative AI and LLMs, AI Automation, AI Agents** course.

The goal of these Day 1 exercises is to gain practical experience building small LLM-powered applications and understanding how prompts, external data, and language models work together.

Each project is implemented and documented in its own Jupyter Notebook.

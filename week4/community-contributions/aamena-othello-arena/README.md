# Othello LLM Showdown

A variant of the Week 4 Connect 4 LLM Arena, adapted to play Othello (Reversi) instead — same LLM-vs-LLM head-to-head format, extended with full Othello rules (legal move validation, piece-flipping, scoring).

**Repo:** https://github.com/Aamena-Ingaria/othello-llm-showdown

Built on top of Ed's original Connect 4 arena code from Week 4.

# If push is rejected after amend (non-fast-forward), use:
git push --force-with-lease -u origin vilas/lab1-solution

# 5) Clear notebook outputs (required for course PRs)

git commit -m "Clear notebook outputs"
git push

# 6) Open Pull Request on GitHub
#    Base repository: ed-donner/llm_engineering
#    Base branch: main
#    Compare branch: vilas/lab1-solution (from your fork)
#    Result: PR #3975

# 7) Clean up local main after PR
git restore uv.lock
git switch main
git reset --hard origin/main

================================================================================
COMMAND CHEAT SHEET
================================================================================

git clone <url>              Download a repo to your Mac
git status                   See changed / staged files
git branch                   List branches (* = current)
git switch -c name           Create and switch to a new branch
git switch name              Switch to an existing branch
git add <path>               Stage specific files (prefer this over git add .)
git commit -m "message"      Save a local snapshot
git push -u origin branch    First push of a branch to your fork
git push                     Later pushes (after -u)
git restore <file>           Discard local edits to a file
git restore --staged <file>  Unstage a file but keep the file on disk
git reset --hard origin/main Make local main match GitHub main
git checkout branch -- file  Copy a file from another branch
git log --oneline -3         Show recent commits
pwd                          Show current terminal folder
export PATH="$HOME/.local/bin:$PATH"
                             Fix "uv: command not found" in that terminal

IMPORTANT RULES FOR THIS COURSE
--------------------------------------------------------------------------------
1. Put your work under community-contributions/vilas_tadoori/ only.
2. Do not commit changes to the course notebooks (week1/day1.ipynb, etc.).
3. Clear notebook outputs before committing.
4. Prefer: git add week1/community-contributions/vilas_tadoori/...
   Avoid: git add .   (can accidentally include uv.lock)
5. If uv.lock is modified, ignore it or: git restore uv.lock
6. PR base must be ed-donner/llm_engineering / main.
7. Do not click "Close pull request" unless you intend to withdraw it.

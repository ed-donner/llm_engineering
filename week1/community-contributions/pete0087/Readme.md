# Marvel AI Character Intelligence Assistant

**LLM Engineering — Week 1 Community Contribution**

An extension of Ed Donner's website summarisation exercise, using Marvel superheroes as a fun way to explore LLM engineering.

Instead of entering a website URL, users enter a Marvel character's name. The application uses OpenAI Web Search and a language model to research the character and generate a formatted intelligence report.

**Features**
- Search for Marvel characters by name
- Generate origin stories, abilities, weaknesses and character relationships
- Compare Marvel Comics and MCU continuity
- Display formatted Markdown summaries and research sources

**Technologies:** Python, OpenAI API, Web Search, Jupyter Notebook and IPython.

**How to run:** Install `openai`, `python-dotenv` and `ipython`, configure `OPENAI_API_KEY`, then run the notebook cells.
